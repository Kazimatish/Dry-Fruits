🥜 Dry Fruits Website

A modern and responsive Dry Fruits Website built using HTML, CSS, and JavaScript.
This project was created as a web development project to practice front-end development, responsive design, and interactive website features.

🌐 Live Website

Live Demo:
https://dry-fruits-ashy.vercel.app/

📌 About the Project

The Dry Fruits Website is designed to showcase different types of dry fruits in a clean and user-friendly interface.

The goal of this project is to create a simple online presence for a dry-fruit business where users can explore products and learn more about the available items.

✨ Features

- 🥜 Dry fruits product showcase
- 📱 Responsive design for different screen sizes
- 🎨 Clean and modern user interface
- 🧭 Easy navigation
- ⚡ Interactive elements using JavaScript
- 📦 Product-focused layout
- 💻 Works on desktop and mobile devices

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive design
- JavaScript — Interactivity and functionality
- Git & GitHub — Version control and project hosting
- Vercel — Website deployment

🚀 How to Run Locally

1. Clone the repository:

git clone https://github.com/Kazimatish/Dry-Fruits.git

2. Open the project folder:

cd Dry-Fruits

3. Open "index.html" in your browser.

You can also open the project in VS Code and use a live-server extension for easier development.
